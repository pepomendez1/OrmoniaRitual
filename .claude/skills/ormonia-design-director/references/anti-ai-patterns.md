# ORMONIA · Anti-AI Pattern Checklist

Use this checklist before approving any new section.

## Common AI tells to reject

### Repeated composition formulas
Reject when multiple sections repeat:
- eyebrow
- huge serif
- 2-line paragraph
- outlined button
- centered composition

### “Premium beige”
Reject generic combinations of:
- cream background;
- elegant serif;
- muted green;
- giant whitespace;
when there is no ORMONIA-specific reason.

### Fake editorial metadata
Do not add monospace or uppercase labels just to make something feel like a magazine.

### Too many cards
Do not turn:
- values;
- ingredients;
- steps;
- quotes;
- editorial content;
all into cards.

### Too many chips
Chips are for interaction or meaningful taxonomy.
Not decoration.

### Same radius everywhere
Avoid making:
- PDP media;
- editorial images;
- cart;
- article cards;
- diagnostic panels
all use the same rounded rectangle language.

### Decorative motion
Reject:
- floating elements;
- automatic parallax;
- random scale;
- scroll-triggered reveals on everything;
- motion that does not communicate state.

### Generic copy
Be suspicious of:
- Descubrí...
- Elevá...
- Transformá...
- Tu viaje...
- Diseñado para vos...
- Una experiencia única...
unless already approved.

### Feature-grid syndrome
Do not solve every content problem with a 3-column grid.

### Gradient syndrome
No large foggy gradients between sections.
No gradient overlays unless local text legibility genuinely needs one.

### Glassmorphism
Avoid glass panels over photography.

### Hero redesign syndrome
The Hero is not a sandbox.
Do not repeatedly redesign approved Hero structure.

### Over-explaining
The brand can leave some ideas implicit.
Do not explain the philosophy in every section.

## Human-design test

Ask:

1. Would a human art director intentionally make this choice?
2. Is this choice specific to this photograph/content?
3. Does this section look different because it NEEDS to, or because we wanted “variation”?
4. If we removed one element, would the composition improve?
5. Is the UI helping commerce/content, or performing “design”?

If unsure, simplify.
